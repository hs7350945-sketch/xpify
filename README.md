# 🎮 XPIFY

## Sobre o projeto

O XPIFY é um projeto acadêmico de uma plataforma social voltada para
gamers, criada com o objetivo de centralizar conquistas, progresso e
interações entre jogadores em um único ambiente digital.

A proposta busca tornar a experiência de jogar mais organizada, social
e motivadora.

## 🎯 Objetivo

O projeto foi desenvolvido para solucionar a dispersão de informações
entre diferentes plataformas e melhorar a forma como jogadores
acompanham seu progresso e interagem com amigos.

## 🚀 Principais funcionalidades

- Cadastro e login de usuários
- Perfil personalizado
- Biblioteca de jogos
- Registro de progresso
- Arquivo de conquistas
- Ranking entre jogadores
- Feed social
- Interação entre amigos
- Sistema de streak
- Gamificação

## 🎨 Experiência do usuário

O projeto possui foco em UX/UI, buscando criar uma interface intuitiva,
responsiva e visualmente atrativa para o público gamer.

## 🛠️ Projeto

Este projeto foi desenvolvido como parte da minha formação em
Engenharia de Software, envolvendo planejamento de sistema,
experiência do usuário e estruturação de uma solução digital.
